# Priyanka Soni — Next.js Portfolio

A responsive, recruiter-focused personal portfolio built with Next.js + React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy

This project is ready for Vercel/Next.js hosting.
